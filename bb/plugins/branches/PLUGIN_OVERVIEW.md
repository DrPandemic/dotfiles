# Branches

Fork a conversation from any message (or a text selection) into a hidden branch that opens in the thread's side panel, so the main conversation stays untouched.

- **Branch from here**: message action (hover bar and text-selection menu). Inside a branch, the same action creates nested branches.
- **Branch panel**: chat with the branch in place, see what it branched from, and merge back a summary or the last reply into the parent, the main thread, or any other branch.
- **Tree**: the header button (with branch count) opens the full branch tree for the conversation.
